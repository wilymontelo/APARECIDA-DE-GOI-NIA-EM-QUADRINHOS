# Aparecida Educação em Quadrinhos

Página estática de vendas do material **Aparecida Educação em Quadrinhos — Professor Pedagogo**.

## Publicação na Vercel

1. Envie esta pasta para um repositório no GitHub.
2. Na Vercel, clique em **Add New > Project**.
3. Importe o repositório.
4. Mantenha **Framework Preset: Other** e **Root Directory: ./**.
5. Clique em **Deploy**.

Não há comando de build: o site está pronto na raiz do repositório.

## Publicação na Netlify

Envie o ZIP final diretamente em **Deploy manually**. O arquivo `index.html` já está na raiz.

## Integrações configuradas

- Checkout PayT.
- Pixel Lowtrack.
- Prévia de áudio local.
- Imagens WebP locais e responsivas.

Todos os recursos necessários estão dentro do repositório. Para mover o site a outra hospedagem, envie a pasta completa sem alterar a estrutura de `assets/`.
